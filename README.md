# 📚 Databricks + PySpark: Meus Estudos

Repositório com os meus estudos do curso **"Aprenda do Básico ao Avançado a Manipular Databricks com linguagem SQL, Python PySpark Para Análise de Dados Cloud"**.

Aqui eu guardo notebooks, exercícios, anotações e projetos que fui construindo ao longo do curso, com foco em **ETL**, **Big Data** e **Lakehouse**.

## 🎯 Objetivo

Consolidar o aprendizado em Databricks, Spark SQL e PySpark, e manter um material de consulta rápida para uso em projetos reais na área de dados.

## 🛠️ Tecnologias

- Databricks (Free Edition)
- Apache Spark / PySpark
- Spark SQL
- Delta Lake
- Unity Catalog
- Microsoft Azure
- Git e GitHub


## 📖 Conteúdo estudado

| Módulo | Tópicos |
|---|---|
| Configuração | Criação de conta gratuita no Databricks, primeiras configurações |
| Organização | Notebooks, hierarquia Catalog → Schema → Tabelas → Volumes |
| Arquivos | `dbutils`, DataFrames, sistema interno de arquivos |
| Formatos | Leitura e escrita em CSV, JSON, Parquet e Delta |
| Particionamento | Particionamento e multiparticionamento de dados |
| Tabelas do sistema | Histórico de queries, performance e custos com DBUs |
| Filtros | `filter`, `where`, `like`, `translate`, `lower`, `trim` |
| Colunas | Criação, colunas condicionais, schema, conversão de tipos, arredondamento e renomeação |
| Datas e horas | Manipulação em PySpark e SQL |
| Nulos | `dropna`, `fillna` e filtragem |
| Agregações | Contagem, média, mínimo e máximo |
| Delta Lake | Logs, restauração de dados e otimização |
| GitHub | Repositórios, versionamento e conexão com o Databricks |
| Azure | Criação de conta e configuração do ambiente |
| Lakehouse | Fundamentos e criação na prática |
| Arquitetura Medalhão | Camadas Bronze, Prata e Ouro |
| Unity Catalog | Volumes externos, gerenciados e External Location |
| Projeto final | Pipeline completo Bronze → Silver → Gold na Azure Cloud |
| Automação | Pipelines automáticos com Databricks Jobs |
